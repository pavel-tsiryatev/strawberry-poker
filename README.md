# 🍓 Strawberry Poker

3D Texas Hold'em на Rust для игры с друзьями по сети: ПК (Windows / Linux / macOS) и Android.
Оформление в духе мобильных покер-клубов: вид на стол сверху, зелёное сукно, кожаный борт
с золотым кантом, объёмные фишки, анимации раздачи и вскрытия.

## Возможности

- Texas Hold'em No-Limit, до 6 игроков за столом, сайд-поты, корректные олл-ины.
- **Игра по сети:** один игрок создаёт стол (хост), остальные подключаются по его IP.
  Хост сам ведёт игру, клиенты только отправляют действия, поэтому чужие карты к вам не приходят.
- **Боты** на свободных местах: хост добавляет и убирает их кнопками «+ Бот» и «×».
  Друг, который подключается к полному столу, садится вместо бота.
- Таймер хода (30 с; по истечении — автоматический чек или фолд), докупка после проигрыша,
  подсказка текущей комбинации, журнал раздачи.
- Тот, у кого оборвалась связь, автоматически сбрасывает карты, а в конце раздачи его место освобождается.

## Как играть с друзьями

1. Хост: **«Создать стол»** → выбрать блайнды, стек и количество ботов → **«Открыть стол»**.
   На экране появится адрес, например `192.168.1.5`.
2. Друзья: **«Подключиться к другу»** → ввести этот адрес → **«Подключиться»**.
3. Хост нажимает **«Начать игру»**.

### В одной Wi-Fi сети
Всё работает сразу: вводите адрес, который показывает хост.
При первом запуске Windows может спросить разрешение для брандмауэра — нажмите «Разрешить».

### Через интернет
Хосту нужен адрес, по которому его видно из интернета. Варианты:
- **Radmin VPN / ZeroTier / Tailscale (проще всего).** Все ставят программу и заходят в одну сеть.
  Друзья вводят адрес хоста в этой сети (например, `26.x.x.x` у Radmin VPN).
- **Проброс порта.** На роутере хоста пробросить TCP-порт `47474`, а друзьям дать внешний IP хоста.

Порт по умолчанию — `47474`. Если он занят, игра возьмёт свободный и покажет его.
Тогда адрес вводится как `IP:порт`.

## Скачать

GitHub Actions собирает игру под все платформы при каждом пуше:
вкладка **Actions** → последняя сборка → раздел **Artifacts**:

| Файл | Платформа |
|---|---|
| `strawberry-poker-android` | APK для Android 8+ (установка из неизвестных источников) |
| `strawberry-poker-windows` | `strawberry-poker.exe` |
| `strawberry-poker-linux`, `strawberry-poker-macos` | исполняемые файлы |

Если запушить тег `v*` (например, `v0.1.0`), файлы попадут в GitHub Release.

## Сборка вручную

```bash
# ПК
cargo run --release

# тесты (логика, оценка рук, сетевая игра через TCP)
cargo test --release
```

На Linux нужны `libx11-dev libxi-dev libgl1-mesa-dev libasound2-dev`.

### Android

Понадобятся Android SDK (platform 35, build-tools), NDK r25+ и JDK 17:

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi
cargo install --git https://github.com/not-fl3/cargo-quad-apk
NDK_HOME=$ANDROID_HOME/ndk/<версия> cargo quad-apk build --release
# APK: target/android-artifacts/release/apk/
```

APK подписывается отладочным ключом. Для домашней игры с друзьями этого достаточно.

## Устройство проекта

| Файл | Что внутри |
|---|---|
| `src/cards.rs` | карты, колода, ГСЧ |
| `src/eval.rs` | оценка комбинаций (лучшие 5 из 7) |
| `src/game.rs` | правила: блайнды, торговля, сайд-поты, вскрытие |
| `src/ai.rs` | боты: эквити методом Монте-Карло + характер (тайтовость, агрессия, блеф) |
| `src/proto.rs` | сетевой протокол (JSON-строки поверх TCP) |
| `src/server.rs` | авторитарный сервер стола, запускается у хоста в фоновом потоке |
| `src/client.rs` | сетевой клиент |
| `src/scene.rs` | 3D-сцена: стол, карты, фишки, кнопка дилера |
| `src/gfx.rs` | 2D-интерфейс поверх сцены |
| `src/main.rs` | меню, экран стола, управление |

Шрифт — DejaVu Sans (лицензия в `assets/DejaVu-LICENSE.txt`).

### Отладочные переменные окружения

- `STRAWBERRY_SHOT=файл.png:сек[:host|hostsetup|joinsetup|join=адрес]` — сделать скриншот и выйти.
- `STRAWBERRY_AUTOSTART=1` — хост сам начинает игру; `STRAWBERRY_AUTOPLAY=1` — сам коллирует.
- `STRAWBERRY_WINDOW=2400x1080` — размер окна (проверить вид на «телефонном» экране).
